# jaspGCEstim 1.0.0

- Added standalone **Ridge Trace**, with automatic or custom lambda grids, cross-validation, and minimum-error, 1-SE or manual penalty selection.
- Added Ridge Trace tables and plots for coefficient paths, prediction errors, coefficient ranges and stability across cross-validation folds.
- Improved handling of optional true coefficients for precision-error plots, allowing other results to remain available when this input is invalid.
- Improved coefficient names, table headings and guidance for analysis controls.
- Widened random-seed fields so complete seed values are visible.
